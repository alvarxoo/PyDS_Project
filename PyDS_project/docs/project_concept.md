# Project concept

Fill in every section. Write for a person who knows nothing about your topic.

## 1. Topic
One sentence: what is the project about?

## 2. Problem
What is unclear, interesting or important here? Why is it worth analysing?

## 3. Goal of the analysis – the question
One concrete question that can be answered with a number, a ranking or a plot.

## 4. Data source
Name, link, licence, who created it, how many rows and columns, what ONE row represents.

## 5. Expected results
What will you show at the end? (e.g. a ranking, a comparison, a map, a trend)

## 6. How you will present it
Which plots / tables, and one sentence for a non-expert: "Our analysis shows that …"

## 7. Team and split of work
Who is responsible for which module (GitHub login of each person).
